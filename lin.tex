\begin{abstract}
A heads-up display (HUD) that augments navigation through translating road signs in real-time. This would be really useful in areas where neighboring countries use different languages, such as Europe or Asia and help drivers quickly understand important information without taking their eyes off the road.

The system would use a vision-language model trained to recognize and translate road signs from multiple source languages into a user-selected target language. The target language would be set by the user via voice commands, such as ``Translate to Spanish.'' Translations would be overlaid digitally within the HUD.
\end{abstract}
